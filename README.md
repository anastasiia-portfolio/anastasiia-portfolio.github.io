# Anastasiia · Portfolio

Сайт-портфолио: Reels, UGC и видео для брендов. RU / ES / EN.

- Ссылка на нужный язык: добавьте `?lang=ru`, `?lang=es` или `?lang=en` в конец адреса.
- Контакты меняются в `index.html`, блок `ВАШИ ДАННЫЕ` в начале скрипта.
- Видео лежат в папке `videos/`: к каждому `.mp4` нужна обложка `.jpg` с тем же именем. Порядок и подписи задаёт список `REELS` в `index.html`; `o: "v"` означает вертикальное видео, `o: "h"` горизонтальное.

Шрифты: Morganite (Rajesh Rajput, freeware, см. `fonts/Morganite-License.pdf`), Involve (OFL, см. `fonts/Involve-OFL.txt`), Oswald (Google Fonts) для кириллицы в заголовках.
